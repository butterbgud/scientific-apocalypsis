## Proposed translation schema

When entries are verified, add language blocks without changing the stable card ID:

```yaml
id: SA-OCR-001
asset: assets/cards/<category>/qr.webp
text:
  ru:
    title: Изучить QR-коды
    body: "..."
  en:
    title: Study QR Codes
    body: "..."
ocr:
  source: backing-sheet-2026-08-02
  confidence: high
  reviewed: false
```

The game can later compile these Markdown entries into locale JSON files; translators will not need to edit card images.
